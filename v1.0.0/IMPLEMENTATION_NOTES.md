# 구현 선택과 검증 범위

- 원본 첨부와 확정 결정은 CODEX_EXECUTION_PLAN.md 및 DECISIONS.md에 보존했다.
- 승하차 0.5초는 0.2초 tick의 누적 시간으로 처리한다. 첫 승차 0.6초, 두 번째 1.0초다.
- 중립 점령은 3인 20초, 적 거점은 중립화 15초 후 점령 20초다. 경합은 정지, 인원 미달은 초기화한다.
- 모든 거점의 한 tick 득점을 처리한 후 승리 판정하므로 100점 초과가 가능하다.
- 같은 유닛의 명령은 priority/tick/cmd_id 순서로 교체한다. 미래 명령은 그 시각 이전 행동을 취소하지 않는다.
- PURCHASE는 원자적으로 비용·인원·spawn 공간을 검사한다. 차체에는 무장 동작이 없다.
- 파일 수 권장치를 넘긴 통합 단계가 있다. 사용자가 남은 전체 구현을 승인한 범위에서 진행했다.
- 모델의 JSON은 엔진이 재검증한다. 기록된 명령과 시뮬레이션 시간으로 리플레이하며 텍스트 재생성은 하지 않는다.
- 난수·명령 큐·진행 중 동작·이벤트를 상태 해시에 포함한다. JSON 복원은 등록된 자료형만 허용한다.
- CPU 학습과 Mac NumPy 추론을 분리했다. 가중치는 Git에 넣지 않고 data/policies에 저장한다.
- 보급 결과는 현재 report의 supply_remaining으로 기록한다. 단순 잔액을 총 소비량으로 보고하지 않는다.
- release map 쌍대 경기의 점수 편차와 작은 PPO의 한계는 RELEASE_STATUS.md에 명시했다.
- Pages Functions는 Access가 없거나 JWT가 틀리면 차단한다. 빌드 성공은 실제 계정 배포 성공이 아니다.
- 남은 외부 검증은 RELEASE_STATUS.md, 실행 절차는 SETUP_ACTIONS.md에 모았다.
