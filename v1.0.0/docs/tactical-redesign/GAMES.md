# 최종 10경기 결과와 해석

수정된 rules3/river-districts v2, seed20000–20004를 진영 교대해 10경기 실행했다. 알고리즘 HQ 평가이며 PPO 업데이트·NIM 교사 호출·렌더링을 수행하지 않았다. 학습 향상 평가가 아니다. 수정 전 진단 10경기는 games-before-side-fix.json으로 분리했다.

총 A5승/B5승/무0. 서쪽 시작8승, 동쪽2승. 팀 문자별 5:5가 위치별 균형을 뜻하지 않는다. 10경기로 유의미한 우세나 원인을 확정하지 않으며 별도 대규모 보류 평가가 필요하다.

실제 실행·결정론 재검증 합계 373.62초. 같은 seed/명령 재실행 checksum 일치. 10개 완료 경기 모두 정상 종료했으나 이는 명령 실패가 없다는 뜻이 아니다.

직사 6087발, 전차 탄착 632회, 포병 탄착 288회, 전차 범위 피해 합계 21351. 실제 아군 피해 합계 7. 피해 엔진에는 아군 피해가 유지되며 아군 위험 후보 제외가 미래 이동/산포까지 무조건 안전을 보장하지 않는다.

수송: 승차 1073회, 하차 1014회. 탑승자는 차량과 중복 표시하지 않는다.

접수 3616건 중 실패 1127건 (31.2%). 주요 사유: BLOCKED 729, TRAFFIC_TIMEOUT 273, ILLEGAL_STATE 56, EXPIRED 42, INSUFFICIENT_SUPPLY 13, UNOBSERVED_TARGET 9, INVALID_TARGET 2, NO_FUEL 2, LANDING_INVALID 1. 취소/실행 중은 실패 집계와 별개다.

차량 교통 대기 757회. 120초 이상 위치가 유지된 활성 이동/대기 표본이 있는 경기 7개. 이 지표에는 의도적 승차 대기 등이 포함되므로 모두 충돌 교착으로 단정하지 않는다.

## 이번에 수정한 원인

- 진영 반전 시 지원 시설 좌표가 따라가지 않던 문제를 수정하고 전체 소유 시설 반전 검사를 추가했다.
- 포병 배치 방향이 A/B 문자에 의존하던 문제를 HQ 실제 위치 기준으로 수정했다.
- 모델 실행 종료 보고의 중복 status 인자 예외를 수정했고, 백그라운드에서 무시되던 SIGINT를 명시적 SIGINT/SIGTERM 안전 경계 종료 처리로 교체했다.

## 남은 개선 우선순위

1. BLOCKED: 분대 대형별 최종 도착 슬롯과 통행 가능 목표 검증. 개별 보병 경로가 있어도 대형 최종 배치가 막히는 경우를 따로 분류해야 한다.
2. TRAFFIC_TIMEOUT: 목표 주변 주차 예약·차량 재시도 간격·장기 승차 대기 진단. 이번 검증의 직접 통행 경로 검사는 동적 다중 차량 병목을 증명하지 않는다.
3. 시작 위치 효과: 동일 정책·상대·seed를 더 많이 교대 평가한다. 샘플 10개 및 알고리즘 HQ의 결과를 PPO 전략 개선으로 해석하지 않는다.

키·모델·대형 리플레이·실행 로그는 Git에 넣지 않았다. 상세 수치는 games.json에 있다.
