# 관전 전장 높이 핫픽스

대시보드로 학습 바를 옮기면서 해당 DOM을 제거했으나 desktop/mobile CSS grid에
학습 바의 auto 행이 남아 있었다. 이후 자식이 한 행씩 앞당겨져 main은84px,
footer는625px(1440×900)로 배치됐다. 렌더러는 잘못된 전장 높이에 맞춰
정상 resize/fit했으므로 지도와 본진 표식까지 작게 모였다.

모든 desktop/mobile grid 선언에서 제거된 행을 삭제하고 전장 행을
minmax(0,1fr)로 명시했다. 1440×900 전장 높이는84→708px,
2936×1596 전장1404px, 모바일390×844 전장630px다. 재생 바는48px로
화면 아래에 고정되고 양팀 목록은 전장 높이 안에서 내부 스크롤한다.
엔진/학습/데이터/관리자 인증은 변경하지 않았다.

검증: 수정 전 동일 증상과 회귀 검사 실패 재현(before.json/이미지).
수정 후 Chromium1440×900/1024×768/2936×1596/390×844 × DPR1/2
8조합에서 실제 캔버스 크기 일치, 남는 grid 행 없음, 전장 높이, 재생 바 위치,
모바일 팀 패널 상호 배타성, 페이지 오류 없음 확인(local.json).
JS45개 및 production build 통과. Production 실제 최신 리플레이 검사 결과는
production.json에 별도로 기록한다.
