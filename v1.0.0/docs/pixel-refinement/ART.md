# 픽셀이 보이는 탑다운 2D

첨부 예시는 둥근 3D 모양이 아니라 픽셀 군집·제한된 색상·단계별 명암의 참고로 해석했다.

- 보병 원본12×20(지원/대전차16×20), 차량 원본30–54px 폭을 게임상60–108px로 확대.
- 지형 원본24×24→48×48, 시설96×80→192×160. nearest 필터로 픽셀 경계를 보존한다.
- 보병/차량은 정수 픽셀·스캔라인 실루엣, 고정 명암 램프와 체크 디더링. 그라데이션/AA 없음.
- 나무는 줄기·불규칙 수관·잎 덩어리와 군집 명암. 임의의 풀 선과 울타리 장식은 제거했다.
- 시설은 작은 원본 해상도로 다시 샘플링하고 명암을 양자화한다.

| 게임 분류 | 실차 외형 모티브 | 식별 요소 |
|---|---|---|
| LUV | Oshkosh JLTV | 짧은 보닛·4륜·작은 객실 |
| APC | FMTV 병력수송형 | 6륜·전방 캡·천막형 수송칸 |
| TRK | Oshkosh HEMTT | 8륜·긴 화물 플랫폼 |
| IFV | M2/M3 브래들리 | 궤도·작은 편심 포탑·짧은 기관포 |
| MBT | M1A2 에이브럼스 | 넓고 각진 포탑·긴 주포·후부 엔진 그릴 |
| SPH | M109A6 | 큰 후방 포실·긴 포신·전개 지지대 |
| HEL | CH-47 | 전후 탠덤 로터·긴 수송 동체 |

“M21 브레들리”는 M2/M3 계열로 해석했다. 외형 모티브이며 성능·크기·게임 판정은
실제 군사 제원으로 바꾸지 않았다. 기존 정원·장갑·가격·이동 수치를 유지한다.

상태창: 체력/탄약/연료/재장전/탑승 meter, 수치, 상태 badge, 사거리/표적.
존재하지 않는 구형 리플레이 값은 추정하지 않고 — 또는 미표시로 처리한다.
