# T20 임무 정상화·NIM 교습

규칙 combined-arms-6, 카탈로그 combined-arms-3, 정책 계약 tactics-4(1600/65).
기존 학습/모델/전적은 보존한다. 구형 5/3 엔진 리플레이 재실행과 checkpoint 재개는 거부하며 화면 재생은 유지한다.

## 구현
- 섬멸: 초기 무장 구매가 총합의 전투 티켓. 추가 무장 자산을 포함한 사망당 차감, 비무장/중립진지 제외. 전투력 소진 또는 티켓0이면 패배.60분 잔여 비율 판정/동률 무승부.
- 깃발: 기존3명/15초 탈취1점,2점 승리. 반납 즉시 승리. 재습득0점,본진 귀환 뒤 새 탈취만 득점.60분 점수 판정/동률 무승부.
- 차량 외부80m 집결,하차,문 통과를 분리한다. 도착 뒤 재승차 반복을 억제한다.
- 탄약 확정값/재보급 이벤트,유한 부분 보급,보급 중 사격 중지,보급차 HQ 재적재/현장 지원. 깃발전 HQ는 외곽 공급 반경23m를 사용해 차량을 실내에 넣지 않는다.
- AA 후보 최소60초 유지/이탈 후60초 재점유 대기,승무원 제외 분대 이동,관측 기반25구역 정찰 순환.

## NIM과 PPO 분리
- 기존 비동기 교사 + 독립 프로세스의 시범/실패 재현. 학습10경기마다 섬멸/깃발 교대 시범. 실패 유형 중복 제거/최근100개 제한.
- 전역 파일 lease로 동시1쌍/30초당1쌍,교습2:일반1 순환.429/네트워크 backoff 공유. 대기 요청을 쌓지 않는다.
- 시범 행동만 별도 모방 표본으로 저장한다. PPO의 경험/GAE/학습 경기/백업 카운터에 넣지 않는다. 양팀 실패 시 표본을 함께 버린다.
- 기존64회차/32표본/0.05/clipping0.5/버퍼10000 유지. 모드13/13/6과 임무 단계 균형,부족시 고유 표본으로 보충.
- 최근30분 실제 학습 CPU에 비례해 시범 CPU 예산을 부여한다. 생성/압축/종료 비용도 계측하고 다음 실행에 반영한다. 인터프리터 시작/마지막 tick에 따른 작은 초과 가능성이 있으며 CPU 예산10%를 절대적 실시간 보장으로 주장하지 않는다.
- 시범은 한 프로세스만,활성 시 시뮬레이션 슬롯을 줄여 중앙+시뮬레이션이4코어 안에서 경쟁한다. 메모리 여유20% 미만/3코어 미만에서는 새 시범을 시작하지 않는다.
- 모델 checkpoint에 교사 버퍼와 중단된 시범 world/큐/난수/진행 상태를 포함한다. 관리자 PPO 정지는 교습도 멈춘다.
- 보류 seed는 교습에서 제외. 실제 NIM 없는 보류 평가만 성능 판단에 사용한다.

## 재개
새 실행 경로: data/mission-normalization-v2. source-archive.json은 GitHub에서 다운로드/체크섬/모델 로딩을 확인한119경기/288세대 두 정책이다.
기존 data/multi-mode-v1의 진단은 수정 전 규칙이므로 재사용하지 않는다. 코드 지문 검증,30경기 결정론 진단,기존 맵 능력 유지,최종 기존 모델 원격 보존을 통과해야 전환한다.

검증 인증서가 준비된 뒤 재개 명령:
`MW_NV_TORCH_THREADS=1 OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MPLCONFIGDIR=/tmp/mw-mpl .venv/bin/python -m learning.mission_pipeline --root data/mission-normalization-v2 --legacy data/league-v1`

동일 초기 모델/고정1작업자/동일 업데이트의 교사 비교:
`MW_NV_TORCH_THREADS=1 .venv/bin/python -m learning.teacher_comparison --root data/teacher-ablation-v2 --source data/mission-normalization-v2/migrated --updates 128`
비교 실행은 결과를 자동 승격하지 않는다. 평가 중 NIM/표본 수집/업데이트는 하지 않는다.

## 검증 상태
실제 통과 수·배포·실행 진행은 validation.json/runtime.json에 기록한다. 통제 장면의 성공은 전체 경기 승리나 전략 향상을 입증하지 않는다. 실제 Intel Mac 성능은 미검증.
