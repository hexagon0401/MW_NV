# T21 복구 경로 집중 점검

수정: (1) 모델 checkpoint의 표본 커서로 되돌려 미저장 교사 표본 누락 방지. (2) PID·시작 시각·작업 경로를 확인해 이전 시범 writer를 종료하고, 완료 작업 재실행 방지. (3) 분할 실행 후 보급·하차·진입 결과를 원래 결정에 누적하고 terminal 이후 NIM 질의 금지. (4) 최대10,000개 전체 표본 대신 현재 결정의 꼬리 표본만 결과 갱신.

관련 회귀16개, 후속12개, 최종 신규 재현5개 통과(중복). benchmark.json은 표본 메타데이터 갱신만 비교하며 전체 시뮬레이션 가속이 아니다. 기존 PPO·optimizer·엔진·에이전트·UI는 변경하지 않았다.

미완료: 새 규칙30경기 진단/기존 맵 유지 검증 및 NIM 비교 대기. 전략 향상·전이 성공은 미입증. 시범 CPU10%는 계측 기반 admission 예산이며 초기화·최종 저장을 포함한 엄격한 OS 한도가 아니다. 즉시 거부 opcode 연계·무탄약 누적 시간 등의 세부 계측도 완전하지 않다.

변경 전후 알고리즘 진단 의존 파일을 바이트 비교하고 완료3개 진단의 해시 검증을 보존해 재개한다. 교습 자체의 성과를 소급 검증하지 않는다. 실제 실행은 runtime.json 참조.
