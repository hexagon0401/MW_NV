# T19 다중 모드 무승부 분석

분석 표본은 engine-audit의 알고리즘 대 알고리즘 진단이다. PPO1/PPO2 또는
NIM 교사 실전 성능의 평가가 아니다. 맵3의10경기, 맵4의3경기는 모두
TIME_LIMIT_DRAW/시뮬레이션60분으로 종료했다. 학습/엔진/설정은 변경하지 않았다.
원시 통계의 제한된 집계와 seed0 양팀 재현 근거는 evidence.json에 있다.

## 1. 깃발탈취: 본진 내부를 차량 집결점으로 사용하는 오류

3경기의 EMBARK_DONE240건, DISEMBARK_DONE0건. BUILDING_ENTERED,
FLAG_STOLEN/FLAG_PICKED_UP/FLAG_MOVED 모두0건. 최초 교전은3경기 모두696초.
차량 파괴는3경기 합계1대, 항공 손실0대였다. 수송/침투 연쇄가 성립하지 않았다.

agents/mission_tactics.py는 enemy_hq.pos를 차량 지원 목표로 넘긴다.
engine/traffic.py의 arrival_slot은 목표 중심부터 주차점까지 vehicle=True로
segment_clear를 검사한다. 깃발실 중심 HQ_FLOOR는 보병만 통과 가능하므로
외부에 합법 주차점이 있어도 중심점 자체가 거부돼 None을 돌려준다.
seed0 양팀9종(LUV/APC/IFV/MBT/SPH/HEL/BH/LB/TRK) 모두 재현됐다.
같은 함수에 본진 외부80m 집결점을 주면 양팀9종 모두 주차점이 생성됐다.
따라서 승차 후보는 있어도 임무 목적지로 운행하는 후보가 누락될 수 있다.

보병의 점 경로와8명 단일열의 개별 경로 계획은 같은 seed에서 양팀 모두
가능했다. 이는 전체 물리 이동·전투 중 진입 성공을 증명하지 않는다.
FORMATION_UNREACHABLE224건, ILLEGAL_STATE152건, UNOBSERVED_TARGET148건도
있어 수송 수정 후 보병의 문 통과와 교전 중 전진을 별도 확인해야 한다.

권고: 차량은 외부 집결/착륙→분산 하차, 보병은 문→깃발실, 운반자는 외부
승차→아군 집결→하차→반납으로 목적지를 분리한다. 통행/벽/탈취 조건은 유지한다.

## 2. 섬멸전: 실제 교전은 있으나 잔존 전투력 정리가 안 됨

10경기 합계 사격31628, 보병 전투불능2829, 차량 전투불능441건.
최초 교전129~134초. 종료 시 팀별 카탈로그상 무장 생존 수7~43,
증원 티켓 전부0, 크레딧15~83, 보급1093~1337이었다.
전장 전체 탄약0 무장 유닛은 경기당1~5개다. 무장 생존 수는 즉시 사격 가능한
유닛 수와 다르므로 이것만으로 최후의 적 위치/실제 전투 가능성을 추정하지 않는다.

현 combat_possible은 탄약0만으로 패배시키지 않고, 무장 생존/구매/중립 진지
운용 가능성까지 보수적으로 본다. 기존 승리 조건상 남은 적을 없애지 못하면
정상적으로 무승부다. 시간만 늘리거나 손실 점수로 승자를 만드는 것은 근본 수정이 아니다.

확인된 비효율: 대공 진지 점유2059건, 이탈2037건. 같은 진지·같은 승무원의
점유→이탈2037쌍에서 중앙값2.2초 만에 이탈했다. 항공기가 안 보이면 승무원을
빼고, 중립으로 바뀌면 다시 점유하는 후보가 반복 생성되는 구조와 일치한다.
약4096개의 점유/이탈 이벤트가 발생했다. 이벤트 수와 HQ 명령 수는 동일한
모수가 아니므로 이를 그대로 명령 낭비 비율로 해석하지 않는다.

추가 원인 후보: 재점유110점, 하차150점, 승차105점 등 고정 점수가 임무 정찰85점
보다 높다. seed0 첫 회차의 상위4개 선택은 두 모드 모두 승차였다. 점수만으로
전체 경기의 우선순위 독점을 확정할 수는 없으므로 시점별 후보/선택 자료가 필요하다.
적 시야가 없을 때 섬멸 정찰 목적지는 고정4지점이라 전장 전체 잔당 탐색을 보장하지
않는다. 현재 통계에는 마지막 교전 시각/최종 위치/정지 지속 시간/실패 명령의 op가
없어, 고립·경로 정체·탐색 누락 중 어느 것이 최종 원인인지 확정할 수 없다.

## 3. 수정과 검증 우선순위

1. HQ 외부 집결점과 수송→하차→문→깃발실 연결을 고친다. seed0/반대 진영
   통제 장면에서 실제 승하차와 깃발실3인 진입을 확인한다.
2. 대공 운용/이탈에 임무 수요와 유지시간·재점유 cooldown을 둔다. 승무원 차출로
   나머지 분대의 임무 후보가 사라지는지도 확인한다.
3. 관측만 사용하는 잔당 탐색·추격과 임무 역할 할당을 보완한다. 보급량은 남지만
   현장에 연결되지 않는 사례를 재보급 완료율로 확인한다.
4. 명령 op별 생성/선택/접수/완료/실패(즉시 submit 거부 포함), 탑승 대기시간,
   마지막 전투·목표 접근·최종 전투 가능 자산을 수집한다.
5. 고정 seed로 기존/수정 알고리즘을 비교한다. 깃발실 진입·수송 완료·탈취·귀환과
   점유 반복 감소부터 확인하고, 승패 변화는 별도 보류 평가로 검증한다.

무승부를 없애기 위한 규칙 완화 대신 실행 가능한 임무 후보와 지휘를 먼저 고친다.
결정론 해시 일치는 이런 잘못된 동작도 동일하게 재현됐다는 뜻이며 임무 수행 능력을
입증하지 않는다. 이번 작업은 분석만 수행했고 자동 전환/학습을 중단하지 않았다.
