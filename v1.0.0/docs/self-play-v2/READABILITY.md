# 전술 가독성과 관전 수정

원형 보병(팀 색·앞쪽 밝은 돌기·뒤쪽 짙은 점), 화면 px 기준 보병24×5/차량40×6 체력바,
파랑/주황 차량 표식과 본진 버튼·미니맵 HQ 문자를 추가했다. 엔진 크기·충돌은 변경하지 않는다.
줌.30 이하 분대 표시, .36 이상 개별 표시로 복귀하며 겹친 같은 분대는 가까이서도 묶는다.
분대 배지는 도보 생존자만 포함한다. 클릭하면 확대한다. 사거리 원은 hover/tap에만 표시한다.

승하차 관계로 리플레이 차량 인원을 재계산하고, 중복 승차·역방향 탐색 검사로 갱신을 확인했다.
불완전한 초기 관측의 기존 인원은 알려진 병사와 차이를 보존한다. 파괴 차량은 탑승0이다.
발사 좌표 메타데이터를 추가하고 오래된 기록은 이동 이벤트 시점 좌표로 복원한다.
사격은80ms 총구/120ms 예광/160ms 탄착으로 표시하며 전투 판정과 RNG는 변경하지 않는다.
