# 자연광 2D 렌더링

UI·게임 좌표·판정·수치는 유지했다. 보병·차량은 원래 표시 크기의 4배 해상도,
시설은 3배, 지면은 2배 해상도로 생성하고 원래 월드 크기로 매핑한다.
공유 아틀라스의 미사용 공간을 줄였으며 렌더 시 필터를 추가하지 않는다.

- 기존 검은 직사각형 외곽 대신 얇은 윤곽·곡면 실루엣과 3단계 셀 명암.
- 차체/포탑의 밝은 윗면·어두운 측면, 유리 반사, 궤도·타이어·적재물 재질.
- 보병의 타원형 헬멧, 조끼·배낭·총구·팔다리와 병종 장비를 별도로 그린다.
- 팀 색은 차체 전체를 칠하지 않고 식별 띠로 사용하며 A/B·병종 표식을 유지한다.
- 지면의 반복 격자·큰 사각 얼룩을 제거하고 낮은 대비 디더링·큰 색 변화·풀잎을 사용한다.
- 수관의 불규칙 외곽, 밝은 북서쪽/어두운 가장자리와 접지 그림자.
- 나무 바닥색을 지면에 맞춰 정사각형 숲 패치 경계를 숨긴다.
- 시설 지붕·입면·출입구·기둥·헬리패드도 같은 재질로 교체했다.

자연광을 연상시키는 미술적 표현이며 물리 기반 조명/동적 태양 시뮬레이션은 아니다.
차량·보병 접지 그림자는 월드 공간에 두어 회전해도 같은 방향에 남는다.

검증: JS 11개, production build, 실제 64+64/10+10 live 장면, hover·모바일 PASS.
`verification.json`의 SwiftShader 소프트웨어 GPU 측정은 12FPS이며, 동시에
가속 경기 검사가 실행 중이었다. Intel Mac GPU 성능은 미검증이다.
`combined-forces.png`는 기물 비교용 합성 배치, 나머지 live 스크린샷과 구분한다.
