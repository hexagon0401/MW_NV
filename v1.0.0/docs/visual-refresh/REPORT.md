# 10경기 가속 검사와 해석

## 실행 조건

엔진 기준 커밋 `2e2f027`. 1024m 출시 맵, 팀당 초기64명·차량10대.
seed0–4를 기본/좌우 반전으로 각1회: 10경기, 독립 seed는 5개다.
양팀 동일 알고리즘 TacticalHQ, 30초마다 의사결정. LLM·PPO는 사용하지 않았다.
물리 tick0.2초는 유지하고 sleep/관전/추론 대기 없이 최대 속도로 실행했다.
재실행: `python -m engine.soak --output data/ten-games.json`.
실행 중 브라우저 검사도 진행되어 실제 시간은 공유 CPU 부하를 포함한다.

총 시뮬레이션 290분 / 실제310.809초(약5분11초), 전체 평균 약56배속.
10/10 종료, A5승/B5승, 무승부0. 9경기는100점 도달, 1경기는45분 종료다.
좌측 진영4승/우측6승. 작은 짝지은 표본이므로 공정성이나 우세의 통계적 증거는 아니다.

## 발견 사항

**P1 — 차량 교통/경로 계획과 재시도 정책**

명령4640건 접수, 실행 실패2433건(52.4%), 완료1858건, 취소345건,
종료 시 비종결 명령4건. 취소는 우선순위 교체이므로 실패에 합산하지 않았다.
차량 TRANSPORT의 PATH_NOT_FOUND가1701건으로 실패의69.9%를 차지한다.
추가 재현에서 실패 차량7개 사례를 라운드 종료 위치에서 정적 지형만으로
다시 탐색하면 모두 경로가 존재했다(`path-reproduction.json`).
동적 차량 점유/교통 병목이 주원인이라는 강한 단서이며, 각 실패 시점의
장애물 스냅샷까지 기록해야 정확한 인과를 확정할 수 있다.
코드상 차량들이 같은 거점 중심/고정 하차 좌표를 공유하고 빈 수송차의
도착 후 주차/퇴거 명령이 없다. 실패한 고득점 후보에 대한 회피·쿨다운도 없다.
개선 우선순위: 분산 하차/주차 슬롯 → 통행 양보/대기 → 실패 후보 감점·재계획.

**P1 — 보병 편대/승차 접근의 혼잡**

BLOCKED577건 중 점령272건, 승차215건, 후퇴46건이다.
편대가 강체처럼 함께 이동하고 승차 접근은 다른 분대와 충돌한다.
승차979명·하차913명이라는 누적 이벤트가 있으므로 수송 기능 자체는 작동하지만,
이는 고유 인원 수가 아니며 정상적인 수송 성공률을 뜻하지 않는다.
개선: 분대별 승차 대기열, 개별 접근 경로, 좁은 통로에서 편대 축소와 재집결.

**P2 — 헬기 착륙/명령 상태와 자원 소진**

LANDING_INVALID30건은 모두 seed0 기본 배치에 집중됐다.
고정 착륙점 반복 선택을 의심할 수 있으므로 대체 착륙장 후보가 필요하다.
ILLEGAL_STATE61건은 수송29·치료12 등이 주류다. 발행 시점과 실행 시점의
상태 차이를 추적하고 불가능해진 작업은 후보 갱신/취소해야 한다.
보급 부족18건, 관측 만료3건, 무효 표적2건은 합법성 검사가 막은 사례도 포함하므로
모두 엔진 버그로 분류하지 않았다. TTL만료41건도 정체/교전 대기와 함께 해석해야 한다.

**P2 — 운용되지 않는 수단과 지시 기아**

일부 생존 병력이 한 번도 이동하지 않았다. 신규 증원이나 정지 지원 차량도 포함되어
이 수치만으로 전원을 고착 상태라고 판단할 수 없다.
다만 알고리즘은 8명 분대 위주 수송이라4인승 LUV에 맞는 작업이 없고,
보급차의 전방 배달 작업도 생성하지 않는다. 역할별 일감과 명령 예산 순환이 필요하다.

## 작동한 기능과 검사의 한계

직사4809회, 포격/탄착303회씩, 차량 전투불능105대, 보병 전투불능828명,
증원604회, 점령60회, 중립화34회, 치료208회, 수리45회가 기록됐다.
포격은 별도 이벤트이므로 직사4809회에 포함하지 않았다.

처리되지 않은 예외/경기 중단0, 제출 경계 거부0. 검사한 좌표 범위·음수 HP·
탑승자 역참조·중복 탑승·정원 초과 위반0.
이는 모든 상태가 올바르다는 증명이 아니며 충돌 겹침·영구 고착·공정성·
LLM 품질·PPO 학습·Mac 성능·관전 재연결을 이10회 검사로 검증한 것은 아니다.

결론: 완주와 전투 기능은 확인했지만, 현재 승패는 교통 병목과 반복 실패에
강하게 오염되어 있다. 경로/운용 문제를 먼저 고친 뒤 같은10개 조건을 재실행해야
전략과 밸런스 비교를 신뢰할 수 있다. 이번 작업은 진단이며 해당 엔진 결함을
수정 완료했다고 주장하지 않는다. 원본 집계는 ten-games.json / summary.json.
