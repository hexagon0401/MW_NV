# 물가 헬기 정지 교정

최신 공개 완료 경기에서 A HEL10208이 깊은 물(220.84,328.40m) 위에서 READY로 남고 LANDING_INVALID165회를 반복했다. B HEL20208은 명령 없는 지상 IDLE였으므로 이 경기에서 B까지 오류라고 판정하지 않았다. 좌우/세 항공기 검사는 별도로 수행했다.

비행 중 새 명령·취소·기한 만료가 기존 명령을 끝내면 CommandQueue.finish가 공중 차량까지 READY로 바꿨다. 다음 이동은 물 위에서 새 이륙을 시도하다 실패했다. 비행 중단은 HOVERING으로 유지한다. 구형 checkpoint의 READY/HOLD 상태도 가장 최근의 미완료 비행 기록과 실제 위치가 일치할 때만 복구한다. 성공적으로 착륙한 최신 기록은 과거 취소 기록보다 우선한다. 물이라는 이유만으로 비행 상태를 추정하거나 육지로 옮기지 않는다.

공중 승하차를 거부하고 기존 공중 대기 연료 소비/소진 판정을 유지한다. 동일 입력·checkpoint의 상태 해시, 양팀·HEL/BH/LB의 물 위 재지시→착륙, 성공 착륙 후 재오인 방지, 기존 수송/전투/리플레이/독립 PPO 회귀40개를 통과했다.

사이트 코드는 바꾸지 않았다. 기존 완료 리플레이는 과거 결과 그대로 남는다. 수정 적용 이후 생성되는 경기부터 정상 비행을 표시한다. 기존 학습 모델·optimizer·전적을 초기화하지 않으며 수정 전 전체 복구본(generation120/50경기)은 원격 검증해 보존했다. 코드/물리 조건이 달라졌으므로 수정 전후 승률 차이를 학습 향상의 증거로 해석하지 않는다. T11의 이전13개 진단은 보존하고 새 물리 코드로 다시 검증한다.
